Pages are processed structurally (the PDF object model) in pure JavaScript — no external library or service. Selected order becomes the output order, so this covers merging across files, extracting a subset, reordering, splitting, and removal. Files are re-written with a fresh object index; page content (text, images, fonts) is carried over verbatim. Rendering/visual previews are not provided; use the page numbers for selection.
