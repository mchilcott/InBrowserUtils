Rendering replays each clip onto a single canvas and records it in one continuous pass with the MediaRecorder API, producing a single valid file with the clips in sequence. The output uses the format/codec selected (WebM on most browsers; MP4/H.264 where supported). Mixed-resolution clips are fitted onto a black canvas of the first clip's size. No external service is contacted — editing happens entirely on this page.
