Uses the Web MIDI API (Chromium, Edge etc.). Input monitor decodes note on/off, control change, program change, pitch bend, channel pressure and common system messages into readable lines, with a per-channel note counter. Output injection lets you send test messages to a selected output to verify routing. Select an input/output to monitor or inject (device listing auto-updates on plug/unplug). Everything is processed locally — nothing leaves the page.
