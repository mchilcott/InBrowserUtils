🎙️ SpeechTranscriber

Live speech-to-text using your browser's built-in speech recognition

Idle — requires Chrome/Edge, or macOS Safari
Transcript

Uses the Web Speech API (SpeechRecognition), which is built into the browser — no external service. Recognition is sent to your browser vendor's speech service (Chrome/Edge online, or Apple's on-device engine on macOS Safari). Language and mode can be chosen; interim mode shows live text in blue. The transcript is editable in place and can be saved as a text file.
