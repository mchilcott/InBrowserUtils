🧰 InBrowserUtils

A set of utilities that run entirely in your browser — no external services

🎥
ScreenGrab
Record your screen and save it as a compressed video file, with format, bitrate and frame-rate control.
Runs anywhere
🔌
SerialConsole
Talk to WebSerial devices. Set baud, word length, parity, flow control and line termination; send and receive live.
Runs anywhere
📡
BlueScan
Enumerate BLE devices and browse the GATT tree — read, write and subscribe to characteristics, like nRF Connect.
Needs secure context (serve over localhost)
✂️
VideoCutMerge
Cut sub-clips from videos, arrange them on a timeline, and render them into a single concatenated output file.
Runs anywhere
🎙️
SpeechTranscriber
Live speech-to-text in the browser with language choice, interim results and editable transcript — saves to a text file.
Runs anywhere
📄
PDFTools
Merge, split and reorder PDF pages entirely in the browser — pick pages from several files and export a combined document.
Runs anywhere
🎹
MIDIDebug
Inspect live MIDI input (notes, CC, pitch bend) with a channel activity counter, and inject test messages to a MIDI output.
Needs secure context / Chromium+Edge

Each tool is a single self-contained HTML file with no dependencies and no build step — just open it in a browser. Everything is processed locally; nothing is uploaded anywhere. The Web Bluetooth tool (BlueScan.html) additionally requires a secure context, so serve the folder over localhost for that one:
python3 -m http.server 8000 → http://localhost:8000/
